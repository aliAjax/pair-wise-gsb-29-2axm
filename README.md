# 城市末端配送模拟 · 出车核验台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

分单完成后，站点在「出车核验台」按波次逐件扫码核验，避免漏件、多件和冻品上常温车，不再等客户投诉才发现。

## 核验流程

1. **新建波次**：记录骑手、车辆温区、包裹编号清单（建波次时对原分配做不可变快照）和计划封车时刻。
2. **扫件上车**：扫码与分单清单逐件比对，实时显示对上 / 缺件 / 多件 / 温区不符 / 无资料。
3. **执行核验**：
   - 完全一致 → 允许封车；
   - 任一不符 → 波次退回「待处理」区，问题逐条登记；原分配清单和已扫记录全部保留，补扫、移下车后可重新核验（第 2 轮、第 3 轮……）。
4. **封车**：确认无误后由操作人封车，过了计划封车时刻会标红提醒。
5. **解封**：封车后的任何修改只能登记解封原因和复核人，解封后重新核验、重新封车。
6. **重开核对**：波次、扫码、问题处理、封车/解封审计全部落在 localStorage，刷新或重开浏览器后可按骑手和波次继续核对。

温区装载规则：常温车只装常温件；冷藏车可装常温 + 冷藏；冷冻车可装常温 + 冷藏 + 冷冻。

## 代码分层

| 目录 | 职责 |
| --- | --- |
| `src/packages/` | 包裹资料层：领域类型、温区/骑手常量、主数据种子与存取 |
| `src/rules/` | 核验规则层：温区装载约束、逐件比对纯函数，不碰存储与页面 |
| `src/archive/` | 本地留档层：波次全过程数据（清单、扫码、问题、审计）的种子与 localStorage 存取、工作流 store、时间工具 |
| `src/components/` | 操作页面：`WaveList`（波次列表/新建）、`VerifyDesk`（核验台）、`ParcelManager`（资料库） |
